==================================================================================
IMPORTANTE: este NÃO é o `npm run typecheck` oficial. O ambiente onde o código é escrito não
consegue baixar `@types/react` (registro npm bloqueado para esse pacote). Para ainda assim
checar o restante do código, rodou-se `tsc --noEmit` com declarações mínimas de React escritas
à mão ("stubs"). Os erros abaixo vêm dessas declarações simplificadas, não do código do projeto:

  TS7006 (73x)  "Parameter 'e' implicitly has an 'any' type"  -> o stub não tipa eventos do React
  TS2882 (1x)   import './styles.css'                         -> declaração de CSS ausente no stub
  TS2614 (1x)   'Fragment' não exportado                      -> stub incompleto
  TS2322 (1x)   prop 'key' em componente                      -> stub não conhece 'key'
  TS2554 (1x)   useState<string | undefined>() sem argumento  -> válido no React real (overload)
  TS2339 (5x)   MouseEvent.button/metaKey/...                 -> stub não tipa MouseEvent
  TS2345 (2x)   useRef<HTMLDivElement>(null)                  -> válido no React real

Nenhum erro de tipos do próprio domínio (types.ts, chamadas à API, props de páginas) apareceu.

(gera docs/evidencias/sprint06/verificacao_pc.txt com a saída de `npm run typecheck`).
